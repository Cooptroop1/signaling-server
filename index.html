Button Help

Start Chat: Starts New Chat

Connect to Chat: This connects you to a chat that you have code for

Send Code: Asks before putting this room on the public random board. Default is off — Text Code is private.

Random Chat: Public board of rooms people chose to post. Anyone can tap a code.

Copy Code: Copies the code so you can send to people in text or social chats

Attach (📷 left of the box): Opens Photos, Camera, File, Voice note and Call. The button then shows the last thing you picked. Send stays on the right.

Voice note: Tap Voice, or the mic on the right when the box is empty. Tap Send to post, Cancel to drop it. Max 30 seconds.

Call: Start from Attach. During a call the left button hangs up and the speaker button appears.

Toggle Grok Bot: Enable/disable Grok bot mode. Requires xAI API key. For details, visit https://x.ai/api.

Text Code: Opens your own Messages app with the join link only. We never send SMS from our servers and we never store phone numbers. If that phone is taken later, the text only shows a code.

Add User: One tap adds one more seat. Same code. Up to 4 stays phone-to-phone. Past 4 switches to encrypted server backup (up to 50). Kick someone from their green dot to throw them out and close that seat.

Phone-to-phone only: Tick this if you never want the encrypted server backup. Green badge = phones talking directly. Amber = backup still encrypted.

Moose (corner): Tap once to burn this phone. Tap twice to wipe everyone still in the room, kill the code, and leave. Switching away for 20 seconds also burns a live room. Text Code and Random Board give you three minutes so you can pick a room or send a text without wiping. Refreshing or closing the tab burns this device.

Claim Username: Claim a persistent username for discoverability. Keys stored locally—new device may lose old offline messages.

Login: Login with your claimed username to retrieve it on new devices and get offline messages.

Search User: Find a signed-up name. Send a sealed invite or note. Inbox, moose book and QR stay on this phone. Rooms still burn.
