How to use

Account

Sign Up with email. You pick a free name. That name is yours to chat with. Login next time. The moose next to your name is your coin count. Tap it to open the shop.

Rooms

Start Chat gives you a code. Send that code. They tap Connect to Chat and type it.

Start 2FA Room is the same, plus a second code so only people with both get in.

Up to 4 people is phone-to-phone. More than 4 uses the encrypted backup.

Close, refresh, leave for 20 seconds, or last person out: the room and the code burn. Nothing is saved.

Tick Same Wi‑Fi when both phones are on the same network.

Send Code (after you start) can put the room on the public board. Leave it off and the code stays private. Random Chat is that public board.

Ask before they join

Tick this before you start the room. Leave it off and anyone with the code walks straight in.

Tick it on and they cannot walk in. They see “Waiting for them to let you in…”. You get a bar with their name, Allow or Ignore, and the phone buzzes. Allow lets them in. Ignore leaves them out. The code alone is not enough while this is on.

The moose in the corner: tap once to burn this phone. Tap twice to burn everyone and kill the code.

Chat

Type and send. Next to send: Keep, Once (photo burns after they tap it), or 10s / 30s / 1 minute on both phones.

The camera button opens photos, a 10 second video note, voice note, voice call and video call. Video notes are live in the room — they are not saved as a recording on the phone.

Double-tap their picture to go full screen. Double-tap again to shrink it. Mute mic if you do not want to be heard.

Photo code

We shrink the photo first, then hide the room code. Send it as a file (Telegram: file, not photo). Sending it as a picture wipes the code.

The photo only works while your room is still open. Leave or burn the room and the invite dies.

Names and friends

Sign up for a name. Search someone. Tap Add friend. They confirm, or they burn (you wait 24 hours to ask again).

Once you are friends you can send a note, a read-once photo, a voice clip, or call them. Poke is just a nudge with no text.

Sealed Notes sit until they open them, or until the timer you set. Missed calls land there too.

Moose Book is names you chose to save. My names is names on your account. Search is for people, not for buying names.

Moose shop

Open Moose shop. Numbers 1–10 cost 100,000 moose. Numbers 11–999 are card. Short is 1–3 letter names (card). Names is extra 4–16 character names (20 moose). Used is names other people listed. Check first, then buy.

My names → Sell: type moose, card, or both. You must keep one name. Free signup names cannot be sold.

Moose coins

Moose are only for this app. 10 moose = £1. Buy a pack (50, 100, 200, 500) or type any amount from 50 up. You pay with card. Coins then sit on your account.

Spend moose on extra names (20), numbers 1–10 (100,000), or a used name if the seller listed a moose price. Shop cut on a used moose sale is 5%. The rest goes to the seller as moose.

Moose cannot be cashed out. They are not money, not a gift card, and not an investment. You cannot redeem them for pounds, bank transfer, or crypto. Unused moose stay on the account. If you spend them on a name, that spend is done. Packs already on your account are not refunded because you changed your mind.

Safety

Nobody sees that you are typing. After a burn there is nothing useful left on the phone.

Lock: Safety → set a 4+ digit PIN → tick Lock app when I leave. Optional Face ID / fingerprint on this phone. Leave the screen and the app is a black lock until the PIN. Three wrong PINs burns the book on this phone.

Home screen (Android): Browser ⋮ menu → Install app. Then open the moose icon.

Home screen (iPhone): Safari → Share (square with arrow, bottom) → Add to Home Screen → Add. Then open the moose icon, not the Safari tab. Calls and sealed notes can ping.

Paid name problems: Moose shop, message admin. Privacy / Terms / Refunds are on the start page.

Button Help

Start Chat: Starts New Chat

Connect to Chat: This connects you to a chat that you have code for

Send Code: Asks before putting this room on the public random board. Default is off — Text Code is private.

Random Chat: Public board of rooms people chose to post. Anyone can tap a code.

Copy Code: Copies the code so you can send to people in text or social chats

Attach (📷 left of the box): Opens Photos, Camera, File, Voice note and Call. The button then shows the last thing you picked. Send stays on the right.

Voice note: Tap Voice, or the mic on the right when the box is empty. Tap Send to post, Cancel to drop it. Max 30 seconds.

Call: Start from Attach. During a call the left button hangs up and the speaker button appears.

Toggle Grok Bot: Enable/disable Grok bot mode. Requires xAI API key. For details, visit https://x.ai/api.

Text Code: Opens your own Messages app with the join link only. We never send SMS from our servers and we never store phone numbers. If that phone is taken later, the text only shows a code.

Add User: One tap adds one more seat. Same code. Up to 4 stays phone-to-phone. Past 4 switches to encrypted server backup (up to 50). Kick someone from their green dot to throw them out and close that seat.

Phone-to-phone only: Tick this if you never want the encrypted server backup. Green badge = phones talking directly. Amber = backup still encrypted.

Moose (corner): Tap once to burn this phone. Tap twice to wipe everyone still in the room, kill the code, and leave. Switching away for 20 seconds also burns a live room. Text Code and Random Board give you three minutes so you can pick a room or send a text without wiping. Refreshing or closing the tab burns this device.

Burn timer: Next to send, pick 10s / 30s / 1 min. That line vanishes on both phones. Keep = normal.

Room QR: In a chat, tap Room QR. They scan it to join. No typing.

Typing: Nobody ever sees that you are typing.

Claim Username: Claim a persistent username for discoverability. Keys stored locally—new device may lose old offline messages.

Fingerprint / Face ID: After Sign Up, tap Save fingerprint. Next time tap Login then Fingerprint / Face ID — no password. First time only: in Supabase go Authentication → Passkeys, turn it on, RP ID anonomoose.com, origins https://www.anonomoose.com and https://anonomoose.com.

Names: Logged-in names are 4–16 letters or numbers. Capitals do not make a new name. Numbers and short names are in the Moose shop. Sold names stay sold. Gold singles can be bid on. Bought names can be listed in Used. Buyer pays the list; Stripe’s fee + 5% comes from the seller.

Call: Logged-in Search or Moose Book → Call. If they have the app open they get a ring (Answer / Decline). If not, it sits in Sealed Notes as a missed call for 30 minutes. Answering joins a phone-to-phone room and starts the voice call. On iPhone: Add to Home Screen and Allow notifications so calls and sealed notes can ping when the app is in the background.

Safety: Logged-in only. Trust names, hide last seen, panic PIN, one-phone lock, disappearing notes, read-once photos, timed meet codes. Wipe other devices burns their inbox and signs them out. iPhone cannot fully block screenshots — the note hides if you leave the app.
